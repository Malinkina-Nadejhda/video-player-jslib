# video-player-jslib

Сайт с кастомным веб видеоплеером. Плеер оснащен собственной панелью: есть кнопки запуска и паузы, включения и выключения звука, а также переход в полноэкранный режим.

---

## Как установить

1. Клонируйте репозиторий на свой компьютер.
2. Убедитесь, что у вас установлен `Python` версии **3.10 или выше**.
3. Используйте `pip` для установки зависимостей:

```bash
pip install -r requirements.txt
```

---

**Запуск сервера:**

```bash
python main.py 
```


После этого переходите по ссылке [127.0.0.1:5500](http://127.0.0.1:5500), вы увидите главную страницу.
